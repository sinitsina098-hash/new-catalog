1\.2 Описание микросервиса

*Notification Service* обеспечивает следующую функциональность:

-  **Управление шаблонами для типов уведомлений**:

   -  Получение списка всех шаблонов.

   -  Получение детальной информации о шаблоне уведомления по его идентификатору.

   -  Создание шаблона уведомления для нового типа событий.

   -  Удаление шаблона уведомлений.

-  **Управление форматами и локализацией шаблонов для типов уведомлений:**

   -  Добавление/изменение HTML формата шаблона уведомления для email.

   -  Добавление/изменение текстового формата (plain text) шаблона уведомления для SMS.

   -  Добавление/изменение JSON шаблона уведомления для push-уведомлений.

-  **Отправка уведомлений пользователям на основе шаблона:**

   -  Отправка уведомления пользователю по предпочитаемому каналу доставки.

   -  Отправка уведомления пользователю по указанному каналу доставки.

   -  Массовая рассылка уведомлений группе пользователей с использованием предпочитаемого канала доставки.

*Предпочитаемый канал доставки - это канал доставки, определяемый на основе пользовательских настроек.*
