### 1\.2 Описание микросервиса

**Fraud detection Service** -- микросервис, который отвечает за анализ объявлений на предмет фрода, их фильтрацию и приостановку.

Функциональность сервиса:

-  Возможность провести скоринг объявления на предмет фрода

-  Возможность автоматически заблокировать постинг объявления

-  Возможность приостановки объявления для ручного анализа

-  *Здесь надо бы добавить пункт про запросы от юзеров в поддержку за неоправданный бан, но пока что выглядит слишком сложно для проектирования и соответствия остальной логике*

-  Скоринг проводится автоматически при каждой попытке публикации объявления

-  Модератор может просматривать, вручную публиковать/блокировать подозрительные объявления

-  Подозрительные объявления
